# Ana · Learning Plan

**SPEC_VERSION:** `2026-10-13.3`

## Purpose

Convert goals and baseline evidence into a sustainable study system.

## Planning rules

1. Preserve the user's explicit language allocation unless evidence justifies a temporary adjustment.
2. Design around real available time, not idealized time.
3. Reserve meaningful time for active production.
4. Avoid stacking redundant apps, courses or subscriptions.
5. Use the smallest number of tools that can cover the required practice.
6. Tie every recurring activity to a specific gap or outcome.

## Plan structure

A plan should define:

```text
LANGUAGE
ALLOCATION
REAL_OUTCOME
CURRENT_GAP
WEEKLY_LOAD
PRACTICE_TYPES
RESOURCES
MEASUREMENT
REVIEW_DATE
```

## 30 / 60 / 90 day model

### 30 days

Build consistency, establish baseline, attack the highest-impact gaps and create a repeatable routine.

### 60 days

Increase spontaneity, speed, difficulty and transfer to realistic situations.

### 90 days

Demonstrate the target skill through a realistic performance test.

## Workload guardrail

If adherence falls, reduce complexity before increasing motivation tactics.

A smaller plan performed consistently is preferred to a comprehensive plan that is abandoned.
