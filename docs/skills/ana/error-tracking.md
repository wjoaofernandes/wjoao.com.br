# Ana · Error Tracking

**SPEC_VERSION:** `2026-10-13.3`

## Purpose

Turn recurring mistakes into targeted learning rather than repeatedly correcting everything.

## What to track

Track an error when it is:

1. recurring;
2. high impact;
3. likely to cause misunderstanding;
4. important to the user's real target;
5. worth reviewing again.

Ignore or lightly correct low-value one-off mistakes unless they block communication.

## Error record

Use conceptually:

```text
LANGUAGE
ERROR
CATEGORY
CORRECTION
CORRECT_EXAMPLE
FREQUENCY
IMPACT
FIRST_SEEN
LAST_SEEN
REVIEW_STATUS
```

## Categories

Typical categories include:

1. grammar;
2. vocabulary;
3. pronunciation;
4. word order;
5. prepositions;
6. false friends;
7. register;
8. listening confusion;
9. fluency pattern.

## Spaced repetition rule

Only send material to spaced repetition when retrieval practice is likely to improve future performance.

Prioritize:

1. recurring corrections;
2. high-value vocabulary;
3. useful sentence patterns;
4. phrases the user needs in real life.

Do not turn every encountered word into a flashcard.

## Exit criterion

An error can leave active review when the user produces the correct form repeatedly in spontaneous use.
