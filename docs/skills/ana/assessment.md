# Ana · Assessment

**SPEC_VERSION:** `2026-10-13.3`

## Purpose

Establish a useful baseline without over-testing.

## Assessment domains

Assess only the dimensions relevant to the target outcome:

1. speaking;
2. listening;
3. reading;
4. writing;
5. pronunciation and intelligibility;
6. active vocabulary;
7. grammar under real use;
8. fluency and hesitation;
9. task-specific performance.

## Method

Prefer demonstrated performance over self-rating.

Use, when appropriate:

1. short self-assessment for orientation;
2. spontaneous speaking sample;
3. listening sample with comprehension questions;
4. short writing sample;
5. realistic task such as an interview answer, work explanation, travel interaction or social conversation.

## Baseline output

Record conceptually:

```text
TARGET_LANGUAGE
TARGET_OUTCOME
CURRENT_LEVEL_ESTIMATE
STRENGTHS
PRIORITY_GAPS
EVIDENCE
NEXT_TEST
```

Do not claim CEFR or another formal level with high confidence unless the evidence supports it.

## Reassessment

Reassess when:

1. a 30/60/90 day cycle ends;
2. the user demonstrates a meaningful jump or regression;
3. the target outcome changes;
4. the current plan no longer matches observed performance.
