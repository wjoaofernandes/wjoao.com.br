# Ana · Conversation

**SPEC_VERSION:** `2026-10-13.3`

## Purpose

Develop speaking, listening, pronunciation and real-time communication.

## Principles

1. Speaking starts early.
2. Meaning and intelligibility come before accent perfection.
3. Feedback should target a small number of high-impact corrections per session.
4. Realistic topics should be preferred over generic textbook conversation when possible.
5. The user should reuse corrected structures in new sentences.

## Practice methods

Use as appropriate:

1. guided conversation;
2. role-play;
3. simulated interviews;
4. simulated meetings;
5. technical explanations;
6. travel and daily-life scenarios;
7. shadowing;
8. retelling;
9. timed speaking;
10. listening followed by spoken reconstruction.

## Shadowing

Use short, understandable audio.

The loop is:

```text
LISTEN
→ REPEAT
→ COPY RHYTHM / LINKING / STRESS
→ RECORD OR SELF-CHECK
→ REUSE THE STRUCTURE
```

## Session quality

A conversation session should produce evidence such as:

1. time spoken without switching language;
2. comprehension rate;
3. recurring errors;
4. pronunciation targets;
5. useful new structures;
6. next speaking task.
