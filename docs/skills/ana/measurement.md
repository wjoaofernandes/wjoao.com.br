# Ana · Measurement

**SPEC_VERSION:** `2026-10-13.3`

## Purpose

Measure real improvement through demonstrated ability.

## Core principle

Study time is an input, not the primary outcome.

## Metrics

Choose only metrics that match the target.

Possible metrics include:

1. uninterrupted speaking duration;
2. comprehension of natural-speed audio;
3. successful task completion;
4. recurring error frequency;
5. active vocabulary retrieval;
6. pronunciation intelligibility;
7. writing clarity and correction rate;
8. interview performance;
9. meeting participation;
10. ability to explain a technical subject;
11. ability to complete a daily-life interaction;
12. CEFR-style performance where appropriate.

## Checkpoints

Use baseline plus periodic checkpoints.

A common pattern is:

```text
DAY 0
DAY 30
DAY 60
DAY 90
```

Adjust when an exam, interview, relocation or other deadline requires a different cadence.

## Evidence hierarchy

Prefer, in order:

1. successful real-world performance;
2. realistic simulation;
3. structured performance test;
4. exercise score;
5. self-rating.

## Definition of Done

A cycle is complete when the user can demonstrate the agreed target at the required level or when the evidence clearly supports the next plan revision.

Completion is not defined by finishing a course, app streak or number of study hours.
