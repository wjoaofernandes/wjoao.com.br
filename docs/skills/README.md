# Ecossistema Laura — Skills

Este diretório documenta a arquitetura operacional das skills pessoais do WJoao Life OS.

## Arquitetura

Laura é a Chief of Staff e coordenadora central. As especialistas decidem tecnicamente dentro do seu domínio; Laura coordena execução, dependências, registro e verificação.

```text
                         JOÃO
                           │
                           ▼
                        LAURA
                  Chief of Staff / Hub
                           │
        ┌──────────────────┼──────────────────┐
        │                  │                  │
     PESSOAL            PATRIMÔNIO         TRABALHO
        │                  │                  │
   ┌────┼────┐        ┌────┼────┐             │
   │    │    │        │         │             │
 Bruna Aline Rosana Juliana  Primo Rico      Regis
   │
 Paulo

                + ANA
          Idiomas / Aprendizado
```

## Princípios

1. Especialista decide tecnicamente → Laura coordena → sistema registra → Laura verifica.
2. Search → Identify → Update → Create.
3. Act → Verify → Reconcile.
4. Uma única fonte da verdade.
5. Fonte oficial antes de memória conversacional.
6. Menos administração, mais execução.
